# Команды консоли

Из папки проекта — `node src/main.mjs <команда>`; из плагина — `node <папка плагина>/dist/ya360-mcp.mjs <команда>`.

| Команда | Что делает |
|---|---|
| `ya360-mcp` | запустить сервер (так его запускают клиенты MCP) |
| `ya360-mcp setup` | мастер: сервисы, вход, проверка, права, подключение к Claude |
| `ya360-mcp doctor` | проверить подключение к каждому сервису (без секретов в выводе) |
| `ya360-mcp login [--manual] [--yes]` | войти через Яндекс; `--manual` — код вручную (SSH), `--yes` — без вопросов |
| `ya360-mcp logout` | удалить сохранённые пароли и токены (config.json остаётся) |
| `ya360-mcp permissions [...]` | показать или изменить права: `read`, `assist`, `full`, группы |
| `ya360-mcp register [code\|desktop]` | подключить сервер к Claude Code / Claude Desktop |
| `ya360-mcp skills install\|remove\|list` | сценарии как личные навыки Claude Code — `/standup` без префикса |
| `ya360-mcp migrate [.env]` | перенести настройки из прежнего `.env` в config.json и хранилище ОС |

## Где лежат настройки

- `config.json`: Windows — `%APPDATA%\ya360-mcp`, macOS — `~/Library/Application Support/ya360-mcp`,
  Linux — `~/.config/ya360-mcp`; другое место — `YANDEX_MCP_HOME`.
- Секреты — в хранилище ОС; переменные окружения (`.env.example` в репозитории) главнее config.json.
