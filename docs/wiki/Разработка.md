# Разработка

```bash
git clone https://github.com/cyxar4uk/ya360-mcp && cd ya360-mcp && npm install
npm test            # проверки без сети
npm run smoke       # сервер как клиент MCP (с вашими настройками)
npm run build       # dist/ya360-mcp.mjs — его запускают плагин и расширение (коммитится)
npm run check:dist  # dist совпадает с исходниками — проверяется и на GitHub
npm run pack:mcpb   # расширение Claude Desktop в release/
npm run wiki:tools  # страница «Инструменты» из сервера
npm run wiki:sync   # выложить docs/wiki в вики GitHub
npm run publish:plugin  # выложить плагин в ветку plugin — её ставят пользователи и берёт каталог
```

## Устройство

| Файл | Что внутри |
|---|---|
| `src/main.mjs` | вход: без аргументов — сервер, с командой — консольная утилита (`src/cli.mjs`) |
| `src/index.mjs` | сервер MCP: сервисы, права, вход из чата, сценарии-подсказки |
| `src/permissions.mjs` | группы прав; новый инструмент без группы не даст серверу запуститься |
| `src/config.mjs` | настройки: окружение → config.json + хранилище ОС → прежний .env |
| `src/oauth.mjs` · `src/login-tool.mjs` | вход через Яндекс: PKCE, локальный адрес возврата, `yandex_login` |
| `src/secrets.mjs` | хранилище секретов ОС без нативных модулей |
| `src/tracker*.mjs` | Трекер: задачи, связи, вложения, время, спринты, люди, активность |
| `src/mail.mjs` · `src/calendar.mjs` | Почта (IMAP/SMTP) · Календарь (CalDAV) |
| `src/scenarios.mjs` | сценарии вне плагина: подсказки Claude Desktop и личные навыки |
| `skills/` | сценарии (навыки плагина); проект — `docs/skills-design.md` |
| `.claude-plugin/` · `packaging/mcpb/` | плагин и витрина Claude Code · манифест расширения Claude Desktop |

## Правила

- Новый инструмент — отнести к группе прав; меняющие данные — выключены по умолчанию.
- Секреты не печатаются и не пишутся в config.json и логи.
- Тексты для модели — коротко: что делает и когда спрашивать согласие.
- Коммит — одно смысловое изменение, `вид: что сделано` (`код`, `правка`, `рефакторинг`, `тесты`, `доки`, `настройка`, `генерация`).
- После изменений в `src/` — `npm run build`, dist отдельным коммитом.

## Выпуск

1. Версия в `package.json` и `package-lock.json`, `.claude-plugin/plugin.json`, `.claude-plugin/marketplace.json`, `src/index.mjs`; запись в `CHANGELOG.md`.
2. `npm run build`, `npm run pack:mcpb`, коммит, отправка; дождаться зелёных проверок.
3. `npm run publish:plugin` — плагин в ветку `plugin`: её ставят пользователи и проверяет каталог Claude. Без этого шага новая версия до них не дойдёт.
4. Метка `vX.Y.Z` и выпуск на GitHub с `release/ya360-X.Y.Z.mcpb`.
