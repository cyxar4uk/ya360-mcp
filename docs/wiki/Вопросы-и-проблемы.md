# Вопросы и проблемы

Первое, что стоит сделать: спросить Claude «какие сервисы Яндекса подключены?» (`yandex_status`) или запустить
`ya360-mcp doctor`. Оба покажут, чего не хватает, и не выведут секретов.

**Инструментов Яндекса нет в чате.** Начните новую сессию после установки или изменения настроек. В Claude Code проверьте
`/mcp` — сервер `ya360` должен быть подключён.

**«Не настроено: вход через Яндекс».** Попросите «подключи мой Яндекс» или выполните `ya360-mcp login`.

**Браузер не вернулся после «Разрешить».** Порт 51734 занят или вход идёт на другой машине — `ya360-mcp login --manual`.

**«Запрашиваемые доступы отсутствуют у данного приложения».** Сервер сам повторит вход без списка прав; если проблема
остаётся — сообщите в задачах репозитория.

**Токен истекает / истёк.** Токен общего приложения действует год — войдите заново: «подключи мой Яндекс» или `ya360-mcp login`.

**Почта: «IMAP не пустил».** При входе паролем приложения: в Почте включите IMAP и «Пароли приложений и OAuth-токены»
(Все настройки → Почтовые программы). В организации Яндекс 360 это может быть выключено администратором.

**Организация запрещает сторонние приложения.** Используйте пароли приложений или своё OAuth-приложение
([[Подключение аккаунта|Подключение-аккаунта]]).

**Трекер: 403 или «организация не найдена».** Проверьте тип и ID организации: Яндекс 360 (admin.yandex.ru) или
Yandex Cloud (console.yandex.cloud).

**Письма по адресу отправителя не находятся.** Поиск IMAP Яндекса не работает по полному адресу — сервер ищет по домену и
сверяет адрес сам; если писем у домена много, сузьте поиск датой.

**Хочу `/standup` вместо `/ya360:standup`.** `ya360-mcp skills install` — см. [[Установка]].

**Инструмента «отправить письмо» нет.** Выключена группа `mail.send` — это по умолчанию. Включить: `ya360-mcp permissions full`
или поле «Права».

**Windows: мастер показывает введённый пароль.** В Git Bash скрыть ввод нельзя — запустите в PowerShell.

**Корпоративный Windows: «хранилище секретов недоступно».** PowerShell в ограниченном режиме блокирует шифрование —
задайте доступы полями плагина/расширения или переменными окружения.
