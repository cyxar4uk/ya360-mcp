# Установка

Три способа — выберите по тому, где вы работаете с Claude.

## Claude Code — плагин (рекомендуется)

Нужен Node.js 20 или новее.

```
/plugin marketplace add cyxar4uk/ya360-mcp
/plugin install ya360@ya360-mcp
```

В терминале то же самое: `claude plugin marketplace add cyxar4uk/ya360-mcp` и `claude plugin install ya360@ya360-mcp`.
Закрепить конкретный выпуск: `claude plugin marketplace add cyxar4uk/ya360-mcp#v0.2.0`.

После установки начните новую сессию и попросите: **«подключи мой Яндекс»** ([[Подключение аккаунта|Подключение-аккаунта]]).

Обновление: `claude plugin marketplace update ya360-mcp`, затем `claude plugin update ya360@ya360-mcp` и новая сессия.

### Команды без префикса

У плагинов Claude Code префикс обязателен: сценарии вызываются как `/ya360:standup`. Если хочется просто `/standup`:

```bash
ya360-mcp skills install     # сценарии как личные навыки в ~/.claude/skills
```

Чтобы сценарии не задваивались, в этом случае подключайте сервер без плагина — способом «вручную» ниже
(`ya360-mcp register`). Вызывать сценарии командой вообще не обязательно: достаточно попросить словами.

## Claude Desktop — расширение

1. Скачайте `ya360-<версия>.mcpb` со [страницы выпусков](https://github.com/cyxar4uk/ya360-mcp/releases).
2. Откройте файл (или Настройки → Расширения → Установить) и включите расширение.
3. В чате: **«подключи мой Яндекс»**.

Node.js ставить не нужно — используется встроенный в Claude Desktop. Сценарии — в меню «+» → ya360:
«Стендап», «Итоги встречи», «План дня», «Недельный отчёт»…

Поля расширения (адрес, пароли приложений, токен Трекера) заполнять не обязательно — они нужны, только если вы входите
паролями приложений вместо «Войти через Яндекс».

## Вручную — любой клиент MCP

```bash
git clone https://github.com/cyxar4uk/ya360-mcp && cd ya360-mcp
npm install
node src/main.mjs setup
```

Мастер спросит, какие сервисы подключить, откроет вход через Яндекс, проверит подключение, предложит права и подключит
сервер к Claude Code и, по желанию, к Claude Desktop. Другой клиент MCP: команда запуска сервера —
`node <папка>/src/main.mjs` (или собранный `dist/ya360-mcp.mjs`), транспорт — stdio.

На Windows запускайте мастер в PowerShell или Windows Terminal — в Git Bash нельзя скрыть ввод паролей (если выберете их).

## Проверка

- В чате: «какие сервисы Яндекса подключены?» — вызовет `yandex_status`.
- В терминале: `ya360-mcp doctor` (из плагина — `node <папка плагина>/dist/ya360-mcp.mjs doctor`).
