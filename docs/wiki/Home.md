# ya360-mcp

Неофициальный MCP-сервер и плагин: Claude работает с **Яндекс Трекером**, **Почтой** и **Календарём** от вашего имени —
находит задачи и письма, собирает стендап и отчёт за неделю, разбирает итоги встреч Телемоста, заводит задачи из писем.
Проект не связан с ООО «Яндекс».

## С чего начать

1. **[[Установка]]** — плагин Claude Code, расширение Claude Desktop или вручную для любого клиента MCP.
2. **[[Подключение аккаунта|Подключение-аккаунта]]** — «подключи мой Яндекс» в чате, одна кнопка «Разрешить».
3. **[[Сценарии]]** — готовые рабочие сценарии: стендап, итоги встречи, план дня, недельный отчёт…
4. **[[Примеры запросов|Примеры-запросов]]** — что можно просить своими словами.

## Как это устроено

```
Claude (Code / Desktop) ──MCP──> ya360-mcp на вашем компьютере ──HTTPS──> Трекер · IMAP/SMTP · CalDAV · OAuth Яндекса
```

- Сервер работает у вас: данные идут напрямую между вашим компьютером и Яндексом, промежуточных серверов нет.
- Токен — в защищённом хранилище Claude или вашей ОС; секрета приложения в коде нет.
- По умолчанию только чтение; запись, отправка и удаление — по группам прав ([[Права и безопасность|Права-и-безопасность]]).
- Всё, что что-то меняет, делается после вашего подтверждения.
