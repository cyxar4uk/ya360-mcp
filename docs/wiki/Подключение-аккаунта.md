# Подключение аккаунта

## Войти через Яндекс (рекомендуется)

**Из чата:** «подключи мой Яндекс». Claude спросит, какие сервисы подключить, для Трекера — ID организации, и откроет
страницу Яндекса. Проверьте аккаунт и нажмите **«Разрешить»** — инструменты появятся сразу.

**Из терминала:** `ya360-mcp login` (или мастер `ya360-mcp setup`). Нет браузера на этой машине (SSH) —
`ya360-mcp login --manual`: откройте ссылку где угодно и вставьте код со страницы Яндекса.

### Что происходит

1. Открывается `oauth.yandex.ru` с запросом прав выбранных сервисов для приложения «ya360-mcp».
2. После «Разрешить» Яндекс возвращает браузер на локальный адрес `127.0.0.1:51734` — код забирает сервер на вашем компьютере.
3. Код обменивается на токен по протоколу PKCE: секрет приложения не нужен, в коде его нет.
4. Токен сохраняется в защищённом хранилище (Claude или ОС), адрес почты берётся из логина Яндекса.

| Сервис | Права |
|---|---|
| Трекер | `tracker:read`, `tracker:write` |
| Почта | `mail:imap_full`, `mail:smtp` |
| Календарь | `calendar:all` |

**Токен действует год.** Продлить его без секрета приложения Яндекс не даёт, поэтому раз в год нужно снова нажать
«Разрешить» — за две недели до срока напомнят `ya360-mcp doctor` и `yandex_status`.

Отозвать доступ: id.yandex.ru → Безопасность → Доступ к данным → ya360-mcp.

## ID организации для Трекера

- **Яндекс 360 для бизнеса:** admin.yandex.ru → Профиль организации → ID.
- **Yandex Cloud:** console.yandex.cloud → Organization → ID.

## Пароли приложений (если организация запрещает сторонние приложения)

- **Почта:** id.yandex.ru/security → «Пароли приложений» → тип «Почта». В Почте: Все настройки → Почтовые программы →
  включить «С сервера imap.yandex.ru по протоколу IMAP» и «Пароли приложений и OAuth-токены».
- **Календарь:** там же, отдельный пароль типа «Календарь» (почтовый не подходит).
- **Трекер:** OAuth-токен с правами `tracker:read`, `tracker:write` — поле плагина/расширения или `YANDEX_TRACKER_TOKEN`.

Вписать — в поля плагина или расширения, или выбрать «пароли приложений» в мастере `ya360-mcp setup`.

## Своё OAuth-приложение

Если организация разрешает только свои приложения: зарегистрируйте приложение на oauth.yandex.ru с нужными правами
и выберите в мастере «своё OAuth-приложение» (вход по коду подтверждения; такой токен продлевается сам).
