# Инструменты

Страница собрана из сервера командой `npm run wiki:tools` — не правьте вручную.
Инструменты выключенных групп прав модели не видны (см. [[Права и безопасность|Права-и-безопасность]]).

## Трекер

| Инструмент | Группа прав | Вид | Что делает |
|---|---|---|---|
| `tracker_whoami` | `tracker.read` | чтение | Текущий пользователь Трекера (логин, имя). |
| `tracker_list_queues` | `tracker.read` | чтение | Список очередей организации: ключ, название, руководитель. |
| `tracker_search_issues` | `tracker.read` | чтение | Поиск задач. Либо query на языке запросов Трекера, например `Assignee: me() Resolution: empty() "Sort by": Updated DESC` или `Queue: PROJ Status: "В работе"`, либо filter — объект полей, например {"assignee": "ivanov", "status": "inProgress"}. |
| `tracker_get_issue` | `tracker.read` | чтение | Карточка задачи: поля, описание, чеклист; по желанию — комментарии, связи, вложения. |
| `tracker_get_comments` | `tracker.read` | чтение | Комментарии задачи, от старых к новым. |
| `tracker_get_transitions` | `tracker.read` | чтение | Переходы статуса, доступные для задачи сейчас (id нужен для tracker_transition_issue). |
| `tracker_get_links` | `tracker.read` | чтение | Связи задачи: relation — кем связанная задача приходится этой («Родительская задача», «Подзадача», «Связана»…), её ключ, статус, исполнитель. |
| `tracker_link_issues` | `tracker.edit` | запись | Связать задачу key с задачей issue. relationship — со стороны key: "relates" — связана; "depends on" — эта задача зависит от указанной (указанная её блокирует); "is dependent by" — указанная задача зависит от этой (эта её блокирует); "is subtask for" — эта задача — подзадача указанной; "is parent task for" — эта задача — родительская для указанной; "duplicates" — эта задача дублирует указанную; "is duplicated by" — указанная задача дублирует эту; "is epic of" — эта задача — эпик для указанной; "has epic" — эпик этой задачи — указанная. |
| `tracker_delete_link` | `tracker.edit` | удаление | Удалить связь по id из tracker_get_links. |
| `tracker_list_attachments` | `tracker.read` | чтение | Файлы, приложенные к задаче: id, имя, размер, кто и когда приложил. |
| `tracker_download_attachment` | `tracker.read` | чтение | Скачать вложение задачи в папку загрузок сервера (<папка загрузок>) и вернуть путь — дальше файл можно открыть обычными средствами. |
| `tracker_upload_attachment` | `tracker.files` | запись | Приложить локальный файл к задаче (до 100 МБ). |
| `tracker_delete_attachment` | `tracker.files` | удаление | Удалить вложение задачи. Необратимо: перед вызовом назови пользователю файл и получи согласие. |
| `tracker_get_worklog` | `tracker.read` | чтение | Записи учёта времени по задаче и сумма в часах (день = 8 ч, неделя = 5 дней). |
| `tracker_search_worklog` | `tracker.read` | чтение | Списания времени человека за период по всем задачам, с суммой по задачам. |
| `tracker_add_worklog` | `tracker.worklog` | запись | Списать время на задачу. duration — «1ч 30м», «2h», «1д» или PT1H30M; start — когда начали (по умолчанию сейчас). |
| `tracker_update_worklog` | `tracker.worklog` | запись | Изменить длительность и/или комментарий записи учёта времени. |
| `tracker_delete_worklog` | `tracker.worklog` | удаление | Удалить запись учёта времени. Перед вызовом назови пользователю запись (дата, длительность) и получи согласие. |
| `tracker_list_boards` | `tracker.read` | чтение | Доски организации: id, название, колонки. |
| `tracker_list_sprints` | `tracker.read` | чтение | Спринты доски по порядку: id, имя, статус (запланирован / идёт / завершён), даты. |
| `tracker_sprint_issues` | `tracker.read` | чтение | Задачи спринта и сводка: сколько задач и очков в каждом статусе и у каждого исполнителя, сколько не закрыто. |
| `tracker_set_sprint` | `tracker.edit` | запись | Поставить задачу в спринт (заменяет прежний спринт задачи). |
| `tracker_find_user` | `tracker.read` | чтение | Найти сотрудника в Трекере по логину, адресу почты или имени (можно неполному: «Андрей Б», «Мария Смирнова»). |
| `tracker_my_activity` | `tracker.read` | чтение | Что человек (по умолчанию — вы) сделал в Трекере за период: создал, сменил статус, закрыл, прокомментировал, изменил поля — по задачам, самое важное сверху. |
| `tracker_add_comment` | `tracker.comment` | запись | Добавить комментарий к задаче. summon — логины, кого призвать. |
| `tracker_create_issue` | `tracker.edit` | запись | Создать задачу. fields — любые дополнительные поля API (sprint, storyPoints, components, tags, followers, deadline, поля очереди). |
| `tracker_update_issue` | `tracker.edit` | запись | Изменить поля задачи. fields — как в API: {"summary": "…"}, {"assignee": "login"}, {"tags": {"add": ["x"]}}, {"sprint": [{"id": 12}]}. |
| `tracker_transition_issue` | `tracker.edit` | запись | Выполнить переход статуса (id из tracker_get_transitions). |
| `tracker_set_checklist_item` | `tracker.edit` | запись | Отметить или снять отметку с пункта чеклиста (id пункта — из tracker_get_issue). |

## Почта

| Инструмент | Группа прав | Вид | Что делает |
|---|---|---|---|
| `mail_list_folders` | `mail.read` | чтение | Папки ящика: путь, назначение, число писем и непрочитанных. |
| `mail_search` | `mail.read` | чтение | Поиск писем в папке по отправителю, получателю, теме, тексту, датам, флагам. |
| `mail_read` | `mail.read` | чтение | Письмо целиком: заголовки, текст (HTML переводится в текст), список вложений. |
| `mail_save_attachment` | `mail.read` | чтение | Сохранить вложение письма в папку загрузок сервера (<папка загрузок>) и вернуть путь. |
| `mail_read_attachment` | `mail.read` | чтение | Текст вложения письма (txt, md, csv, json, html, ics, субтитры) — например, расшифровка встречи Телемоста. |
| `mail_create_draft` | `mail.draft` | запись | Положить письмо в «Черновики», не отправляя. |
| `mail_send` | `mail.send` | запись | Отправить письмо сразу (SMTP). Отправку нельзя отменить: перед вызовом покажи пользователю адресатов, тему и текст и получи явное согласие. |
| `mail_set_flags` | `mail.organize` | запись | Пометить письма прочитанными/непрочитанными и/или важными. |
| `mail_move` | `mail.organize` | запись | Переложить письма в другую папку (archive или путь из mail_list_folders); письма из «Удалённых» можно вернуть этим же инструментом. |

## Календарь

| Инструмент | Группа прав | Вид | Что делает |
|---|---|---|---|
| `calendar_list_calendars` | `calendar.read` | чтение | Календари событий аккаунта (первый — календарь по умолчанию, если не задан YANDEX_CALENDAR_DEFAULT). |
| `calendar_list_events` | `calendar.read` | чтение | События за период с раскрытием повторяющихся. |
| `calendar_create_event` | `calendar.write` | запись | Создать событие. Если указаны attendees, Яндекс разошлёт им приглашения — перед этим покажи пользователю время и список участников и получи согласие. |
| `calendar_update_event` | `calendar.write` | запись | Изменить событие по href из calendar_list_events: название, время, место, описание. |
| `calendar_delete_event` | `calendar.write` | удаление | Удалить событие по href (у повторяющегося — всю серию). |

## Служебные

| Инструмент | Группа прав | Вид | Что делает |
|---|---|---|---|
| `yandex_status` | всегда | чтение | Какие сервисы подключены, каких настроек не хватает, какие группы прав включены и какие инструменты из-за этого скрыты. |
| `yandex_login` | всегда | запись | Подключить Трекер, Почту и Календарь входом через Яндекс: в браузере откроется страница Яндекса, человек нажимает «Разрешить» (ждём до 3 минут). |

## Группы прав

| Группа | Что разрешает |
|---|---|
| `tracker.read` | Трекер: чтение задач, комментариев, связей, вложений, списаний, досок и спринтов |
| `tracker.comment` | Трекер: комментарии |
| `tracker.edit` | Трекер: создание и правка задач, статусы, чеклисты, связи, спринт |
| `tracker.files` | Трекер: загрузка и удаление вложений |
| `tracker.worklog` | Трекер: учёт времени |
| `mail.read` | Почта: папки, поиск, чтение, сохранение вложений |
| `mail.draft` | Почта: черновики |
| `mail.organize` | Почта: отметки и перенос по папкам (кроме «Удалённых» и «Спама») |
| `mail.delete` | Почта: перенос в «Удалённые» и «Спам» |
| `mail.send` | Почта: отправка писем |
| `calendar.read` | Календарь: календари и события |
| `calendar.write` | Календарь: создание, правка и удаление событий |

## Сценарии

В плагине Claude Code — `/ya360:<имя>` (или `/<имя>` после `ya360-mcp skills install`), в Claude Desktop — меню «+» → ya360.

| Имя | Название | Когда |
|---|---|---|
| `day-plan` | План дня | встречи, свободные окна, мои задачи в работе, что горит в почте. |
| `inbox-digest` | Разбор почты | что требует ответа, что к сведению, что можно не читать; по просьбе — черновики ответов. |
| `mail-to-task` | Письмо в задачу | суть, срок, отправитель в наблюдателях, выбранные вложения, защита от дублей; по желанию ответ-подтверждение черновиком. |
| `meeting-followup` | Итоги встречи | из конспекта Яндекса задачи в Трекер с исполнителями и сроками, решения, по просьбе письмо-резюме участникам черновиком. |
| `meeting-prep` | Подготовка к встрече | участники, что обещали в прошлый раз и что сделано, открытые вопросы, что обсудить и подготовить. |
| `setup-help` | Подключение Яндекса | подключить аккаунт, понять, чего не хватает, поменять права. |
| `sprint-planning` | Планирование спринта | перенос незакрытого, загрузка по людям с учётом их скорости, кандидаты из бэклога, задачи без оценок; применение только по явному подтверждению. |
| `sprint-review` | Сводка спринта | сколько задач и очков закрыто, у кого что открыто, что застряло. |
| `stale-tasks` | Кто застрял | по очереди или по моим задачам, сгруппированные по людям; по подтверждению — короткие вежливые напоминания комментарием с призывом исполнителя. |
| `standup` | Стендап | что я сделал в предыдущий рабочий день, что делаю сегодня и что мешает, по Яндекс Трекеру и Календарю. |
| `weekly-report` | Недельный отчёт | что сделано (по результатам, а не списком задач), что в работе, планы, риски. |
