# Как участвовать

Спасибо, что хотите помочь. Проект небольшой, правила простые.

## Разработка

```bash
git clone https://github.com/cyxar4uk/ya360-mcp && cd ya360-mcp
npm install
npm test               # проверки без сети
npm run smoke          # поднять сервер как клиент MCP (с вашими настройками)
npm run build          # собрать dist/ya360-mcp.mjs — его запускают плагин и расширение
npm run check:dist     # dist совпадает с исходниками (проверяется и на GitHub)
npm run pack:mcpb      # расширение Claude Desktop в release/
npm run publish:plugin # выложить плагин в ветку plugin — её ставят пользователи и берёт каталог
```

Нужен Node.js 20+. Код — обычный JavaScript (ES-модули), без сборки для разработки.

## Правила

- **Новый инструмент** отнесите к группе прав в `src/permissions.mjs` — иначе сервер не запустится. Инструменты,
  которые что-то меняют, по умолчанию выключены; отправка и удаление — в своих группах.
- **Секреты** не печатаются, не пишутся в `config.json` и в логи. В сообщениях об ошибках — только имена настроек.
- **Тексты для модели** (описания инструментов, `instructions` сервера) — короткие и точные: что делает,
  когда спрашивать согласие пользователя.
- После изменений в `src/` пересоберите `dist` (`npm run build`) и закоммитьте его отдельным коммитом.
- Коммит — одно смысловое изменение, сообщение в виде `вид: что сделано`, где вид — `код`, `правка`, `рефакторинг`,
  `тесты`, `доки`, `настройка`, `генерация`.
