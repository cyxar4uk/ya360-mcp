# Изменения

## 0.2.0 — 27.09.2026

- Вход через общее приложение проекта на oauth.yandex.ru: код авторизации с PKCE, без секрета приложения;
  из чата — инструмент `yandex_login`, из терминала — `ya360-mcp login`. Токен действует год, за две недели
  до срока — напоминание. Адрес почты — из логина Яндекса.
- Навыки плагина: «Итоги встречи», «Подготовка к встрече», «Стендап», «Недельный отчёт», «Письмо в задачу»,
  «Кто застрял», «Планирование спринта» (проект — docs/skills-design.md).
- Почта: точный поиск по адресу отправителя и получателя (IMAP Яндекса не ищет по полному адресу);
  чтение текстовых вложений с поиском фрагментов и говорящим — для расшифровок Телемоста.
- Трекер: поиск людей, активность за период по истории изменений, защита от дублей задач по метке источника,
  срок, оценка и спринт в карточке.
- Календарь: ссылка на видеовстречу у событий.
- Проект называется ya360-mcp; лицензия MIT; проверки на GitHub (Windows, macOS, Linux; Node 20 и 22).

## 0.1.0 — 27.09.2026

- Первая версия: Трекер (задачи, связи, вложения, учёт времени, доски и спринты), Почта (IMAP/SMTP),
  Календарь (CalDAV); права по группам; настройки в профиле пользователя и секреты в хранилище ОС;
  мастер настройки; плагин Claude Code и расширение Claude Desktop.
