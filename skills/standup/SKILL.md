Собери стендап. Ничего не меняй. Аргументы вызова: $ARGUMENTS

## 1. Период
Пояс — `yandex_status.timezone`. «Вчера» — предыдущий рабочий день: в понедельник — пятница, в выходные — пятница.
Дата в аргументах — её.

## 2. Что сделано
`tracker_my_activity` с `from` — начало того дня, `to` — начало следующего.
- Активности нет — отступи ещё на один рабочий день и скажи об этом («в пятницу в Трекере ничего не было, беру четверг»).
- Сведи **по результатам, а не по событиям**: «PROJ-41 — довёл до ревью», а не пять смен полей.
  Порядок важности: закрыл (`importance` 5) → сменил статус (4) → создал (3) → ответил в комментариях (2) → правил поля (1).
  Мелкие правки (`importance` 0) не показывай. Комментарий показывай, только если это содержательный ответ (см. `comments`).
- Больше 6 пунктов — оставь главное, остальное одной строкой: «и ещё N задач по мелочи».
- Встречи того дня — `calendar_list_events`: название и длительность, если были.

## 3. Сегодня
- `tracker_search_issues`: `Assignee: me() Resolution: empty() "Sort by": Updated DESC`, `limit: 30`.
  Бери задачи в работе и на проверке (по статусу), со сроком (`deadline`) сегодня–завтра — отметь срок.
- Встречи сегодня — `calendar_list_events` на сегодня.

## 4. Мешает
- Мои задачи в статусах ожидания — по названию статуса («Требуется информация», «Ожидает», «Blocked» и подобные).
- Просроченные сроки: `Assignee: me() Resolution: empty() Deadline: < today()`.
- Задачи, заблокированные другими, — если по ним есть связь «зависит от» незакрытой задачи (`tracker_get_links`, только для задач «Сегодня»).
Ничего — «ничего».

## Вывод
```
Вчера (пт, 26.09)
• Закрыл PROJ-41 — выгрузка отчёта в Excel
• Довёл PROJ-45 до ревью
• Встреча «Разбор требований», 1 ч
Сегодня
• PROJ-47 — экран настроек (в работе, срок завтра)
• 11:00 — встреча с подрядчиком
Мешает: PROJ-52 ждёт ответа от Андрея с 24.09
```
Ключи задач — ссылками. От первого лица, без вводных. «Коротко» в аргументах — по одной строке на блок, чтобы прочитать вслух за полминуты.
