Собери отчёт за неделю. Ничего не меняй. Аргументы вызова: $ARGUMENTS

## 1. Период
Пояс — `yandex_status.timezone`. По умолчанию — с понедельника по сегодня; в понедельник до полудня — прошлая неделя целиком. Неочевидно — спроси.

## 2. Данные
- **Сделано**: `tracker_search_issues` — `Assignee: me() Resolved: "<с>".."<по>"` (даты ГГГГ-ММ-ДД), `limit: 100`.
- **Как двигалось**: `tracker_my_activity` за период — смены статусов, созданное, ответы.
- **В работе**: `Assignee: me() Resolution: empty() "Sort by": Updated DESC` — статусы, сроки (`deadline`), сдвинутые сроки.
- **Спринт** (если задана доска по умолчанию): `tracker_sprint_issues` без аргументов — мои очки: закрыто / осталось.
- **Время**: `tracker_search_worklog` за период. Записей нет — раздел **не показывай** (не пиши «0 часов»).
- **Встречи**: `calendar_list_events` — число и часы. Конспекты недели (`mail_search`, тема «Конспект встречи») — по одному ключевому решению с встречи.

## 3. Как свести
- Закрытые задачи группируй по родителю или эпику (`tracker_get_issue` → `parent`, только если групп неочевидно), иначе по компоненту или по смыслу. На группу — одна фраза результата и ключи.
- Больше 30 закрытых — только группы, без перечисления.
- Не выдумывай влияние и цифры, которых нет в данных.

## Вывод — для себя (по умолчанию)
```
Неделя 22–26.09
Итоги
• <3 главных результата>
Сделано
• <группа>: <результат> — PROJ-41, PROJ-45
В работе
• PROJ-47 — экран настроек, срок 30.09
План на следующую неделю
• <ближайшие сроки и незавершённое>
Риски
• <просрочки, блокеры, перегруз — или «нет»>
Цифры: закрыто 9 задач (14 очков) · встречи 6 ч
```

## «Для руководителя»
Короче: 3–5 пунктов результатов языком результатов, риски и что нужно от руководителя. Предложи письмо — `mail_create_draft`, только черновик и только по «да».

## «По команде»
По исполнителям: `tracker_sprint_issues` (сводка `byAssignee`) и закрытые задачи очереди за период (`Queue: <очередь> Resolved: >= "<с>"`). Без оценок людей — только факты.
